# საწვავის ხარჯის კალკულატორი — LPG / ბენზინი

**მისამართი:** https://lpg.qgis.ge/

უნივერსალური ვებ აპლიკაცია, რომელიც ეხმარება ნებისმიერ მძღოლს გაზომოს მარშრუტი
რუკაზე, შეადაროს LPG-სა და ბენზინის ხარჯი, და ნახოს **დღევანდელი საწვავის ფასები**
საქართველოს კომპანიების მიხედვით — ვის აქვს ყველაზე დაბალი ფასი დღეს.

---

## მთავარი ფუნქციები

### 🗺️ უნივერსალური რუკა (A → B)
- დააკლიკეთ რუკაზე ორ წერტილს და მიიღეთ მანძილი.
- ორი რეჟიმი: **მარშრუტი (გზებით)** — რეალური გზის მანძილი [OSRM](https://project-osrm.org/)-ით,
  და **სწორი ხაზი** — პირდაპირი (haversine) მანძილი.
- ღილაკით მანძილი პირდაპირ გადადის კალკულატორში.
- რუკა კონკრეტულ მარშრუტზე მიბმული აღარ არის — მუშაობს ნებისმიერი A→B წყვილისთვის.

### 🧮 საწვავის ხარჯის კალკულატორი
- LPG და ბენზინის (რეგულარი 91/92 · პრემიუმი 95 · სუპერი 98) ხარჯის შედარება.
- ითვალისწინებს ოქტანობის ეფექტს მოხმარებაზე.
- ასამაღლების (total ascent) ენერგეტიკული დანამატის თეორიული გათვლა.
- CSV ექსპორტი.
- „Forester default" ღილაკი — მანქანის პარამეტრების სწრაფად შესავსებად.

### ⛽ დღევანდელი ფასები (live)
- 8 კომპანია: **სოკარი, გალფი, ვისოლი, რომპეტროლი, პორტალი, ქონექთი, ლუკოილი, ნეოგაზი**.
- კატეგორიების მიხედვით დალაგებული იაფიდან ძვირისკენ (რეგულარი / პრემიუმი / სუპერი / დიზელი / LPG / CNG).
- ღილაკით ყველაზე იაფი ფასები ავტომატურად ჩაისმება კალკულატორში.
- მონაცემი ავტომატურად ახლდება GitHub Actions-ით (ყოველ 3 საათში).

## პროექტის სტრუქტურა

```
index.html                     # საიტი (რუკა + კალკულატორი + live ფასები)
data/prices.json               # გენერირებული ფასების მონაცემი
scraper/scrape.mjs             # dependency-free Node scraper
.github/workflows/update-prices.yml   # cron ავტომატური განახლება
```

## ფასების ხელით განახლება (ლოკალურად)

```bash
node scraper/scrape.mjs
```

დაწერს `data/prices.json`-ს. საჭიროა Node 18+ (native `fetch`).

## ტექნიკური სტეკი
- სტატიკური საიტი — HTML / CSS (Tailwind) / vanilla JS.
- რუკა: [Leaflet](https://leafletjs.com/) + OpenStreetMap tiles, მარშრუტი OSRM-ით.
- scraper: Node.js, გარე დამოკიდებულებების გარეშე.
- ჰოსტინგი: GitHub Pages (`lpg.qgis.ge`).
